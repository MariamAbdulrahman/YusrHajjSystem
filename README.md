# Yusr (يُسر) - Hajj Campaign Management System 🕋

A comprehensive system designed to manage Hajj campaigns efficiently. Built with Flutter, ASP.NET Core, and SQL Server.

*(Note: The main repositories are currently hosted privately by the development team. Full access can be provided upon request.)*

**Technologies Used:**
- Mobile App: Flutter & Dart
- Backend: C# & ASP.NET Core
- Database: SQL Server
- Design: Figma
